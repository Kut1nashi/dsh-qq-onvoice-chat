## 3. 本机旧版 FFmpeg 记录

本机 FFmpeg 4.3.2 对一条 220,975 样点的真实未降噪音频：

| 指标 | 结果 |
| --- | --- |
| 输出帧数 | 220,975（不变） |
| `anchor_difference_db` | −0.000003 |
| `clipped` | 0 |
| 额外 100 ms 保护区内未输出 | 1,375 帧 |
| `no_missing_selected_samples_filled` | true |
| 对齐相关 | 0.99968 |

旧版 FFmpeg 的 `afftdn` 会少输出固定数量样点（本机测得 48 kHz 下约 1,403–1,405 帧），这正是 EOF 保护存在的原因。该记录只代表这一条音频与本机这一个二进制，不外推到所有版本、所有音色。

## 4. 明确没有证明的事

- 没有证明“任意新句子只套全局参数就能得到 rep 的效果”——rep 是具体样本的具体渲染结果。
- 没有证明生产环境任意句子的底噪问题已解决；缺少同一次请求的降噪前后配对音频。
- 频段能量下降不等于真实 SNR 提升；RMS 匹配不等于感知响度一致。
- 0.90 不代表“气声减少 10%”，也可能削弱部分辅音。
- 没有新增训练权重，也没有验证训练侧收益。
