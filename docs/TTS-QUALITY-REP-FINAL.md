# REP-final 音质方案说明

版本标识：`nf43-r4-hf90-rep-final`
产物类型：后处理配方（`postprocess_recipe`），**没有新增可训练权重**。

## 1. 它是什么

这是一套作用在**合成之后**的音频处理链，不改变 GPT / SoVITS 权重，也不改变推理参数（seed、采样步数、参考音频等）。它解决的是合成结果里的宽带底噪和局部高频毛刺，不解决发音、韵律或音色本身的问题。

处理链：

```text
合成 WAV（48 kHz / mono / PCM16，未降噪）
  → 全局 NF43（一次）
  → 可选 R4：局部频谱清理（区间由调用方给出）
  → 可选 HF90：区间内 6 kHz 以上分量 ×0.90
  → 一次性 PCM16 量化
```

## 2. 全局 NF43

| 项 | 值 |
| --- | --- |
| 滤镜 | `afftdn=nr=12:nf=-43:tn=0` |
| 输入 | 48 kHz / 单声道 / PCM16 |
| EOF 保护 | 末尾追加 4800 零样点，保证旧版 FFmpeg 的尾部丢帧落在保护区内 |
| 对齐 | 互相关测量延迟，正延迟按正确方向切片补偿；最大 ±2400 样点 |
| 电平 | 以原声 20 ms RMS > −35 dBFS 的窗为参考，固定增益修正，绝对值 ≤1 dB |
| 量化 | 浮点中间结果，最后一次性 PCM16 四舍五入，无静默削波 |

要点：旧实现里“滤镜输出不足就补零”会伪造样点；本实现只在额外保护区内允许未输出，选中的每一帧都来自真实滤镜输出（`no_missing_selected_samples_filled: true`）。

## 3. R4 局部频谱清理

只在你明确给出的区间内生效，窗外逐样点不变。

| 项 | 值 |
| --- | --- |
| 分析 | FFT 2048、hop 512、Hann、加权重叠重建 |
| 低电平代理 | 区间内 RMS > −65 dBFS 的帧，每频点功率取第 15 百分位，再在对数功率域做 5 bin 平滑 |
| 增益 | `sqrt(max(0, 1 − 0.60 · proxy / signal))` |
| 频段保护 | ≤160 Hz 增益 1；400–4500 Hz 弱频点下限 0.90；高频段下限由区间 `highFloor` 决定 |
| 强频点保护 | 功率 ≥ 代理 30 倍或 > 本帧半谱 1% 时，增益 ≥0.995 |
| 平滑 | 5 bin 频率平滑 + 3 帧 `0.25/0.5/0.25` 时间平滑，平滑后仍受下限约束 |
| 电平 | 每窗以原声参考窗做固定增益匹配，绝对值 ≤0.30 dB |
| 边缘 | 40 ms 余弦过渡，完全位于窗口内部 |

## 4. HF90

在指定区间内用居中 129 tap、6 kHz 的 FIR 分出互补高频，按 `y = x − 0.10·w(t)·(x − lowpass(x))` 处理，窗口中部相当于保留 0.90 倍高频分量。

**0.90 是幅度系数，对应高频能量约 −19%，不是“气声被精确削掉 10%”。** 高频里同时有气声、齿音、辅音和噪声，是否接受只能靠听。

## 5. 区间

区间是**每条音频自己的**，本项目不做自动识别。没有区间时只执行全局 NF43，并返回 `no-regions` / `denoise-only`，不会凭空生成时间窗。

发布包里的 `examples/regions.example.json` 只是格式示例；冻结验证用过的两个区间（2.5–4.5 s、7.5–9.5 s）只属于那一条私有测试音频，没有写进任何默认配置。

## 6. 可复现性与边界

- 冻结参考结果为私有回归样本，SHA256 `5a482dc0…37b5351`；发布包不含任何音频，因此**公开环境只能验证算法与接口，无法复现这个哈希**。
- 公开测试全部使用运行时生成的信号，不依赖角色音频、参考音频或本地路径。
- 该方案只证明“某一具体样本的最终听感 + 一套可复用的实现”，不能保证换句子后只调全局参数就得到同样效果。
- 对训练语料预处理属于另一件事，未评估，不建议默认批量套用。
